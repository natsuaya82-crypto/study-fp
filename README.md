# study-fp

ファイナンシャル・プランニング技能検定（FP技能士）の学習用リポジトリ。

**受検予定：3級 2026-10-02 → その後2級**

## 学習アプリ（スマホ用）

https://claude.ai/artifact/WXKFEUed3QdpWuVvAMYdHK

ブラウザで開くだけで使えます。ホーム画面に追加しておくと起動が速いです。

- **教科書**：6分野48章。頻出論点にしぼった解説＋具体例＋暗記ポイント
- **演習**：172問（○×・三択）。分野別／章別／ランダム20問
- **模試**：本番と同じ60問構成。合格ライン36問で判定
- **弱点**：間違えた問題が自動で溜まる。そこからの再出題と、忘れた頃に出る復習テスト

解答の記録はアカウントに保存されるので、端末を変えても引き継がれます。

## 構成

```
app/index.html   アプリ本体
app/data/f1〜f6.js  教科書データ（分野別）
app/data/q1〜q6.js  問題データ（分野別）
SCHEDULE.md      10/2までの学習スケジュール
notes/           手書きメモ用（分野別）
drills/          紙の過去問などの記録用
```

教材を直すときは `app/data/` を編集します。アプリは同じ内容を読み込んでいるので、
リポジトリが教材の正本です。

## 法改正についての注意

税率・控除額・年金額などは毎年改正されます。特に**基礎控除と給与所得控除**は
令和7年・令和8年と2年連続で改正されており、受検回の法令基準日によって正解が変わります。

- 2026年6月〜2027年5月実施分の法令基準日：**2026年4月1日**（受検案内で必ず確認）
- この論点はアプリの「タックスプランニング」の先頭章に、注意書きつきでまとめてあります
- 金額を伴う論点は、受検年度のテキストで最終確認してください

一方、配偶者控除38万円・扶養控除・医療費控除の10万円基準などは変わっていません。
