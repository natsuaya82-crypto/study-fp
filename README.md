# study-fp

ファイナンシャル・プランニング技能検定（FP技能士）の学習用リポジトリ。

## 構成

```
notes/     分野別ノート（6分野）
drills/    過去問・問題演習の記録（間違えた問題の棚卸し）
progress.md  学習の進捗チェック
```

## 使い方

1. テキストを読んだら、該当分野の `notes/` に「自分の言葉で」要点を書く
2. 覚えられない数値・要件は各ノートの「暗記ボックス」に集約する
3. 問題を解いたら、間違えたものだけ `drills/` に記録する（正解した問題は書かない）
4. [progress.md](progress.md) のチェックを進める

## 注意：法改正

税率・控除額・保険料率・年金額などは**毎年改正される**ため、このリポジトリには
具体的な数値をあらかじめ書き込んでいません。
受検年度のテキスト・法令基準日に合わせて自分で埋めてください（それ自体が良い暗記になります）。

- 法令基準日：1月・5月試験 → 前年10月1日 ／ 9月試験 → 当年4月1日
  （※受検回ごとに必ず公式の案内で確認すること）
